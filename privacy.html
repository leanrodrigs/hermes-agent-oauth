Privacy Policy

Last updated: 19 October 2026

This policy applies to the Google Cloud OAuth application hermes agent (Google Cloud project number 219383701433), used only by Leandro Rodrigues.

Who this is for

A single user: Leandro Rodrigues, email leanrodrigs@gmail.com. There are no other customers and no public sign-up.

Google user data we access

With the user’s explicit OAuth consent, Hermes Agent may access:

  • Gmail — read, send, and modify messages (including labels and drafts) to triage email and send mail the user asked to send.
  • Google Calendar — read and write events to keep and create commitments.
  • Google Drive — read and write files the user asks the assistant to handle.
  • Google Contacts — read-only, to resolve names and addresses when needed.
  • Google Sheets and Google Docs — read and write documents the user asks the assistant to handle.

The assistant does not request Google account password. Access is via OAuth tokens stored on machines the user owns.

How the data is used

Google user data is used only to perform tasks the user requests on his own account (read inbox, send a message, create a calendar event, open or edit a file). It is not used for advertising, analytics products, training public models, or resale.

How the data is stored and shared

OAuth tokens live on the user’s Mac, PC, and private VPS. Email and file contents are processed to complete a task and are not uploaded to a separate vendor database. Data is not sold. Data is not shared with third parties except Google, as required to call Google APIs, and except when the user explicitly asks to send a message or share a file.

Retention and deletion

Tokens remain until the user revokes access or deletes them from his machines. To revoke Google access at any time: Google Account permissions. After revoke, the assistant cannot call Gmail or the other Google APIs until the user authorizes again.

Limited use

Hermes Agent’s use of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.
