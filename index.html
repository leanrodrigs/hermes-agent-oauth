Hermes Agent

Hermes Agent is a personal automation assistant used only by Leandro Rodrigues (leanrodrigs@gmail.com) on machines he owns.

It is not a public product, store, or multi-user service. The Google Cloud OAuth client named hermes agent lets this assistant access Gmail, Google Calendar, Google Drive, Google Contacts, Google Sheets, and Google Docs on his account, so it can read and send email, manage calendar events, and work with his files.

Data stays on his devices and on Google’s APIs. It is not sold and is not shared with other people.
